HAIR ROUTINE — первая версия

Файлы:
- index.html — приложение
- manifest.webmanifest — настройки установки
- sw.js — офлайн-кэш
- icon.svg — значок

Как открыть:
1. Распакуйте ZIP.
2. Для простого просмотра откройте index.html в браузере.
3. Для установки как PWA файлы нужно разместить на HTTPS-хостинге (например, GitHub Pages); затем открыть ссылку в Chrome на планшете и выбрать «Установить приложение» / «Добавить на главный экран».

Важно:
- Данные и фото пока хранятся локально в браузере планшета.
- Не очищайте данные сайта/браузера.
- Экспортируйте резервную копию из вкладки «Напоминания».
- Настоящие фоновые напоминания в этой первой версии пока не реализованы: кнопка проверяет разрешение браузера, но не планирует уведомления при закрытом приложении.
